How It Works

1

Start the Miner

Click the button. LongShot connects to a public solo mining pool via the Stratum protocol — the same protocol ASIC miners use.

2

Hash Away

Your CPU computes SHA‑256d hashes. Each one is a lottery ticket. Most will be worthless — your computer is 10 million times slower than a mining rig.

3

Beat the Odds

One in several trillion chance per block. But if lightning strikes and your hash solves the block? You collect the full 3.125 BTC reward. All or nothing.

This is a demo. Real mining requires connecting to a Bitcoin node or Stratum pool. The hash stream shown here is simulated. The odds calculations are real — based on actual network difficulty. LongShot is a Python CLI tool you can run on your own machine. Zero dependencies. Pure stdlib.
